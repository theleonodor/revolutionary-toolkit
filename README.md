# Revolutionary Toolkit

An educational resource on protest rights, organizing history, and social movements — built with Astro and Starlight.

## Local Development

```
npm install
npm run dev       # dev server at localhost:4321
npm run build     # production build to ./dist/
npm run preview   # preview the production build locally
```

## Content

All documentation lives in `src/content/docs/` as `.md` or `.mdx` files. Each file is a route; frontmatter controls the title, description, and sidebar position.
