# Contributing to Revolutionary Toolkit

Contributions happen through Git and GitHub. There is no forum, no Discord, no automated review pipeline — a maintainer reviews pull requests on GitHub when they can.

## To submit a change

1. Fork [theleonodor/revolutionary-toolkit](https://github.com/theleonodor/revolutionary-toolkit)
2. Clone your fork and run `npm install`
3. Start the dev server: `npm run dev`
4. Create a branch, make your changes in `src/content/docs/`, commit, and open a Pull Request

## To suggest a resource without coding

Open a [GitHub Issue](https://github.com/theleonodor/revolutionary-toolkit/issues). Include the source, URL, which section it fits, why it belongs, and any relevant content warnings.

## Content standards

- Verify sources. Provide citations and links.
- Respect copyright. For excerpts, provide commentary and context (fair use).
- No doxxing. Never include personal identifying information.
- Operational security. No current organizing details. Educational and historical focus only.
- Flag potentially traumatic or difficult material with content warnings.
- Use descriptive alt text for images.

See the [full contributing guide](https://theleonodor.github.io/revolutionary-toolkit/contributing/) for more detail on file structure, frontmatter format, and writing style.
