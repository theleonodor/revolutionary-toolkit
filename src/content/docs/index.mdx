## Getting Started

1. **Explore the structure** — use the sidebar to browse sections.
2. **Find your focus** — identify which areas match what you need right now.
3. **Download resources** — save important documents for offline access.
4. **Contribute** — this toolkit is maintained in the open on Git. See the [Contributing Guide](/contributing/) to add or correct material.

:::tip[First time here?]
Start with the [Introduction](/intro/) to understand how the toolkit is organized and how to get the most out of it.
:::

:::note[How this is maintained]
This is a static, open-source reference. There is no account, forum, or platform to sign up for — everything lives in the [Git repository](https://github.com/theleonodor/revolutionary-toolkit), and changes happen through pull requests and issues. See [Contributing](/contributing/).
:::
